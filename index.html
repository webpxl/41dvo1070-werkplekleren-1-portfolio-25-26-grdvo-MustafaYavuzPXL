Niet-schoolprojecten

Niet-schoolproject

MustiBoard

MustiBoard is mijn eigen versie van een Soundboard voor Discord. Het idee is dat je geluiden kan beheren en ze via je microfoon kan laten afspelen tijdens het praten of gamen met vrienden.

  • Mijn rol: ik werkte dit project uit als een eigen tool voor mijn Discordgebruik.
  • Wat je ermee kan doen: geluiden uploaden, categorieen maken, filteren en snel terugvinden.
  • Belangrijkste functie: geluiden laten afspelen via je microfoon, zoals bij je kan doen bij de originele Soundboard dat te verkrijgen is op Steam.
  • Wat ik leerde: zo'n tool moet niet alleen werken, maar ook snel en overzichtelijk blijven in gebruik.

Niet-schoolproject

Booooosted website voor mijn Discordserver

Dit is een website die ik maakte voor mijn Discordserver met vrienden. Het is een eigen hub waar we niet alleen samenkomen, maar ook clips, posts en leuke extra's op één plaats kunnen terugvinden.

  • Mijn rol: ik werkte de website uit als een centrale plek voor onze vriendengroep.
  • Wat je ermee kan doen: clips uploaden, simpele games spelen en een blog/feed gebruiken die werkt als een eigen versie van X.
  • Extra functies: de site heeft verschillende pagina's zoals home, clips, blog, spellen en online/community-onderdelen.
  • Wat ik leerde: zo'n project toont hoe je een communitysite niet alleen mooi, maar ook bruikbaar en leuk kan maken.
